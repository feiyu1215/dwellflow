# 装修同步小程序

> 2026-10-09 接手 R8 请先阅读 [R8 完整 PRD](docs/r8/装修同步_R8_完整PRD与分阶段开发交接_待评审_2026-10-08.md)、[R8-0 开发交接](docs/r8/装修同步_R8-0D_开发交接与阶段验收记录_2026-10-08.md)、R8-1A～[R8-1F 阶段记录](docs/r8/装修同步_R8-1F_v2写入切换与迁移专项验证_阶段记录_2026-10-08.md)、[R8-2A 阶段记录](docs/r8/装修同步_R8-2A_空间模型与旧房间映射_阶段记录_2026-10-09.md)、[R8-2B 阶段记录](docs/r8/装修同步_R8-2B_一等证据对象与关联_阶段记录_2026-10-09.md)及 [R8-2C 阶段记录](docs/r8/装修同步_R8-2C_证据查看器与记录入口_阶段记录_2026-10-09.md)。R8-2A 微信端已由用户确认正常；R8-2B/2C 已完成源码与自动化验证，等待微信端真实文件和媒体行为验收。**正式二维巡场、正式半圆导航和完整视觉仍未迁入。**

面向家庭装修的原生微信小程序。当前采用最低成本的本地运行方式，先把不依赖 AI、监控和施工方注册的日常业务做完整；云端多人协作与真实设备联调延期到准备体验时。

## 当前可用功能

- 创建、切换和编辑装修项目，维护当前工序与项目负责人。
- 在项目内新增、改名、排序、停用和恢复稳定空间；人工整理旧房间标签，登记非比例空间关系，并由负责人记录各空间的阶段状态。
- 将照片、文件和旧记录附件登记为一等证据，保存本地原件引用、大小和 SHA-256；支持缺失/篡改状态、隐藏恢复及独立业务关联，解除关联不删除原件。
- 归档项目后统一只读；负责人可留原因重新开启。项目可移入 30 天回收站并恢复，删除时旧成员、分享和设备授权立即失效且不会随恢复复活。
- 保存文字、照片、语音和文件记录；补录实际发生日期；修订生成新版本，旧内容保留。
- 将现场记录转为问题事项；参与者提预案，负责人采用或替换；提交处理结果后复查、退回、关闭和重开。
- 建立材料约定，经历草稿、送审和负责人批准；登记采购、到货、可用入库、待退与实际退货。
- 按不可变事件记录领用、现场退回、供应商退货、损耗和盘点调整，阻止负库存。
- 分开记录报价、负责人批准增减、付款事实、付款确认、原付款退款和退款确认。
- 展示目标预算、报价、已批准、净付款、待确认金额，以及材料数量、单价和损耗估算。
- 管理本地成员范围与撤销状态，生成只含所选资料的限时固定摘要。
- 建立外部咨询草稿，明确问题、事实、缺口、待回答条目和资料范围；发布固定版本后可复制资料包，按转述或本机成员本人填写回填回复，由负责人转为待选预案或记录不采纳原因。
- 生成包含 JSON、离线 HTML、CSV 和原件的可移植资料；导入前校验文件、业务关系与范围，并恢复为独立只读副本。旧成员、分享与设备权限不复活。
- 查询首批装修检查知识卡；七类 AI 任务均有入口，AI 不作为人工流程前置条件。
- 从待核对到货批次发起“材料到货核对”，锁定一个材料和一个批次，显式选择约定、采购、记录及图片；按品牌、型号、规格、数量逐项复核并保存独立核对记录。AI 采纳不会自动入库、退货、批准或付款。
- 记录整理可生成记录新版本，图片观察可按人工选择创建待确认问题；整改辅助分为拟预案与复查参考，咨询整理分为准备咨询与整理回复，均保留来源并由负责人决定写回。
- 预算辅助只让 AI 提取有来源参数；负责人确认后由程序计算含损耗需求、库存/在途/待核实资源缺口、整包数量和金额，并保存估算版本，不自动采购、批准或付款。
- 项目总结先固定工序、房间、日期与截止时间，再生成进展、问题、材料、费用、咨询五分区草稿；负责人逐节复核后保存报告版本，并纳入完整备份、离线 HTML 和 CSV，不自动发布或改变业务状态。
- 模型任务在服务端后台运行，提交后立即获得任务 ID；取消会丢弃晚到结果，失败或取消只能由用户显式按原资料重试。历史展示重试关联、版本、耗时、token 和今日调用数。
- 使用版本化 Prompt、严格 JSON/引用校验、任务幂等和用量/耗时记录；提供真实模型评测、断点进度和费用快照工具。AI01—AI07 已完成公开/合成小样本真实 API 基线。
- 旧版 13 个页面曾完成公共表单、提示、空态和弹层样式收口；这不等于 R7/R8 正式视觉已落地。当前 R8 生产界面仍混有旧页面、临时概览壳和兼容节点详情，正式 UI 需随 R8-2～R8-5 逐批替换并在微信端验收。

## 当前运行边界

- 小程序业务页使用微信本地存储和本地持久文件，适合开发展示和单机验证。
- 本地结构化业务状态在应用启动时迁移到 `renovation-sync-state-v2`；只有候选写入、二次读取和校验通过后才切换活动指针。旧 v1 key 暂时保留只读，R8-6 前不自动清理。
- 服务端的身份、权限、SQLite 事务、附件与同步模块已存在，但当前页面没有强制接入云端；因此不能宣称跨设备同步或真实多人权限已完成。
- 新版可移植资料会复制原件并用大小和 SHA-256 校验；缺原件的部分包可阅读但禁止恢复。旧版 v1/v2 JSON 仍可能只含本机路径，恢复前会明确列出缺口。
- 分享快照当前是可复制的结构化资料包，不是需要逐次服务端鉴权的在线 H5。
- 外部咨询同样采用本地固定资料包；已复制到外部的内容不能远程收回。“成员本人填写”仅用于同机流程体验，在真实登录接入前不代表已验证身份。
- AI01—AI07 的专用输入、结果、人工纠正、幂等写回或报告留存和备份恢复已通过模拟模型验证；真实项目资料、专业人员和微信端交互尚未验证。
- `deepseek-flash` + Prompt `2026-09-26.2` 在 7 个自制合成视觉用例上达到 7/7 用例、111/111 断言和 6/6 关键用例通过；这是历史评测版本。当前 Prompt `2026-09-27.3` 补充历史已批准约定规则，本轮只完成确定性回归，尚未重新执行付费视觉评测。以上均未验证真实工地的光照、透视、反光、污损、小字和复杂背景。客户端不保存模型密钥。
- 监控页只保留供应商适配边界和接入前置校验。真实观看需要小程序 AppID、供应商账号、兼容设备和双端验收。
- 目前不邀请外部用户体验，也不为展示版购买云资源。
