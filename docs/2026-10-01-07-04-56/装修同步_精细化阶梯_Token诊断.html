你觉得它糙，不是因为没素材

我把 app.wxss 全文跑了一遍量化审计。结果指向一个和「素材」完全无关的答案——下面这批合子里数和告警都是实跑出来的，不是我编的。

病灶是相邻层级的区分度不够：两个间距差 1px、两个字号差 0.5px。

肉眼能感觉到「没对齐」，但说不清哪里没对齐。这种不确定感累积起来，就是你说的「抽象、丑陋」。它跟有没有好看的图片毫无关系，一把没校准的尺子，量什么都不会整齐。

02

为什么 AI 生成的东西确实糙

你的直觉是对的，三条机制
A
精致感的本质是「可复现的确定性」，而 AI 是掷骰子
「精细」不是画得细，是某个边框必须在某个位置、恰好 1px、恰好某个色值。AI 每次生成都在重新采样，你没法说「把这个圆角从 28rpx 改成 32rpx」，只能重生成一遍然后赌它这次改对。没有微调能力的工具，做不出精细的东西。
B
精致感来自层级密度，AI 一次生成把所有层压平成一层
你放大一个真正好的网站会发现它不是一层，是 6–8 层：底色 → 微渐变 → 噪点 → 顶部 1px 高光 → 内容 → 描边 → 分层阴影。AI 出图把这些全糊进一层像素里，远看像，近看就散。这就是你说「非精细化」的物理原因。
C
模型学的是分布的中心，产出的是「平均脸」
大家都在做的样子，恰恰是不够精致的样子。精致需要偏离平均值，而偏离需要有人拍板。这一步 AI 替不了。
结论

AI 适合做某一「层」里的那个资产，不适合做「合成」。你要的是合成结果，不是资产本身——这就是为什么无论跑多少次生图，你拿到的都不是你想要的东西。
但反过来有个好消息：把「糙」变「精」的六件事里，一件素材都不需要。下一节我证明给你看。

L1–L3 是最大的杠杆

间距 / 字阶 / 圆角这三层，一分钱素材都不用，也不改任何一个色值，观感就有台阶式变化。你现在 90% 的「糙」在这三层里。

L6 的噪点是隐藏武器

纯色背景是廉价的头号来源。一层 2.8% 不透明度的噪点，纯 SVG 滤镜生成，不需要任何图片文件。加上卡片顶部那道 1px 白色内阴影，塑料感立刻消失。

L5 阴影要分层

现在只有单层 0 4rpx 20rpx rgba(0,0,0,.04)。真实世界是两个光源：环境光（大扩散低不透明度）+ 主光（带方向）。叠两层才有体积感。

05

那素材这一层到底怎么办

诚实版，AI 能做什么不能做什么
AI 能做 · 单体资产

一次一件，不要一次一页

一个空状态插画、一张纹理、一组图标的方向稿、一张引导配图。让它出「零件」，不是出「成品」。零件可以用代码框在正确的位置上，成品不行。

AI 别做 · 整页

整页生图是死路

因为它是位图：文字没法改、间距没法调、深浅色没法切、数据没法套。你最后会面对一个好看但不能用的东西。这就是你反复踩到的那个坑。

装修场景 · 特殊约束

工地照片必须真实

这条是反直觉的：你的产品里，AI 生成的「现场照片」会直接摧毁信任。用户拿它记录纠纷、留证、给工长看。精修的实时.Apply末端在这里恰恰是扣分。AI 该做的是「把真实照片整理好」，不是「生成照片」。

小程序还有两条硬限制，得提前认

① 字体：中文字体包动辄几 MB，小程序有包体和加载限制，基本只能吃系统字（PingFang SC）。所以「换字体」这条路性价比极低，别指望靠字体出高级感——正因如此，间距和字阶才更重要。
② 渲染：不支持全部 CSS 特性，backdrop-filter 在低端机上会掉帧。上面六层里除了 L6 噪点需要验一帧，其余全是零风险的纯数值调整。

审计可复现：_token_audit.js 在工作区，指向任何 wxss 都能重跑。
本页未修改任何源码。

如果要动手，我建议这个顺序：
  1. 先只做 L1–L3（间距/字阶/圆角）——只改 app.wxss 一处，14 个页面同步受益，零素材零风险，做完立刻能感觉到区别
  2. L4 色彩层级 + --green 改名 + .pill 并轨——同样单点改动，但会大面积覆盖视觉效果，需要过一遍页面
  3. L5 阴影分层——只动两个变量
  4. L6 噪点——先在真机验一帧再决定要不要上
  5. 素材层最后做，且按「按 disadvantage 单体零件」的方式做
