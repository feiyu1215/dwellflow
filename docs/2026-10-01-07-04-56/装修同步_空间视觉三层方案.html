装修同步 · 空间视觉方案

选户型 → 出场景 → 巡场 → 进房间

三层空间视觉：户型层用轴测（二维上表现三维）做场景预览与巡场地图， 具体房间层用纸绘二维做真实巡场。全程不用真实照片素材，也不用纯 3D。

先认一条：我把"写实"理解窄了

上一轮我说：写实 = 你家实拍 / 写实渲染 / 真实家装素材。 → 这条划掉。

错在哪：我把"写实"等同于"真实照片"，把一条活路锁成了死胡同。你从没要求真素材——你要的是能认出是房间、能看出空间关系，那其实网上找个不错的 2D/3D 装饰素材就够，不必实拍、不必渲染。

修正后的口径：场景预览层用现成装饰素材转绘；房间层用 2D 纸绘；需要体积感时用轴测（isometric）——在二维上把三维画出来，不是真三维模型。纯 3D 明确否掉。

口径对照：之前 vs 现在

把你这三轮纠正过的东西一次性钉死，后面任何人接手都不会再绕回去。

层级我之前说的（错的）你现在定的
场景预览 / 户型 必须真实家装写实素材（实拍 / 渲染） 网上找 2D 或 3D 装饰素材转绘，表达房间分布即可，不必真实
具体房间巡场 ① 一度写成"必须实拍"；② 一度写成"抽象分割方块" 2D 纸绘风房间：手绘线 + 纸噪 + 轴测体积感
三维感怎么来 没说清楚 在二维上表现三维（isometric 轴测），不是真三维模型
纯 3D 未排除 明确否——丑、做不出来、也不好表现
工地现场照 （更早）工地照片必须真实 深海是风景、工地不是。现场照是运行时 UGC，不是设计素材

还差你一句话的东西

  • 1. 这套轴测户型 + 纸绘房间的方向，你觉得对路吗？对路我就把剩下几个户型（含跃层 / 复式可能）和全部房间类型补齐。
  • 2. 房间层的纸绘：强手绘（线条明显抖动、更像手画）还是克制手绘（本页这样，只是略有笔触感）？
  • 3. 户型层要不要保留"墙"？本页画的是有墙的立体块；另一种更扁平的做法是纯地板色块 + 描边（接近户型图）。两种都合理，看你喜欢哪个。
  • 4. 网上素材定位：做参照（只在画图时参考气质）还是直接改写（买素材后转成这套语言）？后者要留意版权。
